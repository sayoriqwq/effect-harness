# Hand Target Adaptation to a delivered skill

Effect Harness delivers its Target-aware adaptation skill and supporting
knowledge through Prelude, then performs a Control Handoff: the skill inspects
the real repository, selects package roots, proposes reviewable Target-owned
TypeScript configuration repairs, and returns to the ordinary plan, apply, and
check lifecycle. Prelude core owns only the safe, hashed convergence of the
exact tsconfig Output declared by Effect Harness; it does not discover
TypeScript projects, infer business topology, or add a generic Conformance
protocol. This deliberately trades an impossible claim of complete automatic
coverage for Target-local judgment made explicit in config, diffs, Plan
locators, and final Target Checks, and supersedes ADR-0006.
